# DoloresDeFlorist 🌸

A full-stack web app for a flower shop, built with **React** on the frontend and **Spring Boot** on the backend.

## Features
- Browse seasonal bouquets and arrangements
- Add to cart and place orders
- Schedule delivery windows
- Admin dashboard for inventory and order management

## Tech Stack
| Layer     | Technology              |
|-----------|-------------------------|
| Frontend  | React                   |
| Backend   | Spring Boot (REST API)  |
| Database  | [e.g. PostgreSQL / MySQL] |

## Getting Started
1. Clone the repo
2. Run the Spring Boot backend (`./mvnw spring-boot:run`)
3. Start the React frontend (`npm start` in `client/`)
4. Open http://localhost:3000
